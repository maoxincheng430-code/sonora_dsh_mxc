# 点这里启动喵 🐟

双击就能用的启动脚本：

| 脚本 | 作用 | 什么时候用 |
| --- | --- | --- |
| `启动网站.cmd` | 启动本地网站并自动打开浏览器。首次运行会自动 `npm install`。 | **最常用**，日常都用这个 |
| `启动桌面版.cmd` | 构建后用 Electron 打开桌面版窗口。首次会下载 Electron 运行时（约 100MB）。 | 想要独立窗口 / 系统声音采集 |
| `安装在线音乐依赖.cmd` | 安装 QQ 音乐与网易云两个辅助服务的依赖。 | **想用「在线音乐」面板时先跑一次** |

## 在线音乐要先装依赖

「在线音乐」面板（QQ 音乐 / 网易云 / 酷狗）依赖两个独立的小服务：

```
tools/qq-api   → 端口 3200
tools/netease  → 端口 3202
```

它们是独立子项目，主项目的 `npm install` **不会**带上。不装的话，点开面板只会看到
`Failed to fetch`。

**解决办法**：双击一次 `安装在线音乐依赖.cmd`，装完后正常启动网站即可。

## 登录是你自己的账号

装好依赖后，打开「在线音乐」面板点「扫码登录」，用**你自己的** QQ / 网易云 App 扫码即可。

登录状态保存在 `tools/*-api/.auth-state/`，**只存在这台电脑上**，不会上传，也不会跟着
代码仓库走。换电脑需要重新扫一次。

## 小技巧

- 建议把这三个文件（或整个文件夹）**拖到桌面建快捷方式**，用起来更顺手。
- 也可以直接在项目根目录用命令行：

```sh
npm run dev              # 网站
npm run desktop          # 桌面版
npm run server           # 只启动 API（在线音乐需要）
```
