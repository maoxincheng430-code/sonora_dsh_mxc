# 夕阳海滩场景实现笔记（beach-lab.html）

> 单文件、零依赖，双击即可打开。画面分三层烘焙 + 五类动态系统。
> 布局：**左边是海（分层涌浪 + 碎浪 + 礁石），右边是被浪反复打湿的沙滩（螃蟹、小鱼、贝壳）**。

---

## 1. 构图：斜向岸线 + 消失点

- 地平线在 `0.30H`，太阳落在地平线左侧海面上（`0.19W`）。
- 岸线不是竖线，而是一条从**画面左下 (0.20W, H)** 收向**右上消失点 (0.70W, 地平线)** 的曲线：

```js
function shoreXAt(y) {
  const t = (y - horizon) / (H - horizon);   // 0 远 → 1 近
  const k = Math.pow(t, 1.38);               // 近处变化更快
  return lerp(W * 0.70, W * 0.20, k) + 弯曲扰动;
}
```

- 这样才有「站在沙滩上沿着海岸线望出去」的透视：海在左上，沙在右下，浪线斜着推进。
- `segs[]`：把岸线切成 64 段，每段记录 `{ y, t, sx, wet, reach }`，所有湿沙/泡沫/浪花都基于它，天然贴合岸线。

## 2. 分层

| 层 | 内容 | 频率 |
| --- | --- | --- |
| 烘焙层 | 夕阳天空/云/海鸟、海面底色、沙滩纹理/贝壳、礁石剪影 | 只在 resize 时重画 |
| 浪 | 8 条浪线 + 浪脊高光 + 浪后暗带 + 浪尖白沫 | 每帧 |
| 水 | 水面碎光、夕阳反光带、泡沫拉丝 | 每帧 |
| 湿沙 | 常驻湿带 + 上冲水膜 + 泡沫前缘 + 潮痕 | 每帧 |
| 动物 | 5 只螃蟹、7 条小鱼 | 每帧 |
| 粒子 | 礁石浪花、沙粒、风沙 | 每帧 |

## 3. 海浪：一条浪线的生命周期

每条浪有相位 `p ∈ [0,1)`，`p` 从 0 到 1 表示浪从远处推到岸边：

```js
const depth = Math.pow(p, 1.5);                                  // 透视压缩
const yBase = horizon + (H - horizon) * (0.015 + depth * 0.99);  // 由远及近
const amp   = (1.1 + 18 * p) * ampSeed;                          // 越近越高
const thick = (7 + 46 * p) * thickSeed;                          // 越近越厚
const foam  = clamp((p - 0.35) / 0.65, 0, 1);                    // 越近越白
```

- 浪脊：一圈正弦叠加的曲线（`sin(x*0.0055 + t)` + `sin(x*0.013 - t)`），再加一点沿 x 的倾斜，避免变成水平横条；
- 浪身：脊线到脊线 + thick 之间填充，颜色从青绿渐变到白，`foam` 越大越白；
- 浪后暗带：加深一道，让浪有体积；
- 浪尖白沫：沿脊线撒不规则椭圆，`p` 越大越多；
- 出现/消失：`vis = clamp(p/0.12) * clamp((1-p)/0.1)` 做淡入淡出，避免突然出现。

> 关键：**浪的 y 位置由相位决定、并在画面内推进**。不要用「以消失点缩放岸线」的方式画浪（会让浪被推出画面，海面反而变空）。

## 4. 沙滩被浪打湿（湿沙系统）

- **常驻湿带**：紧贴水线永远有一条湿沙，宽度 = `maxReachAt(t) * (0.3 + 0.62*wet)`；
- **上冲周期**：`0~0.4` 平静、`0.4~0.58` 冲上沙滩、`0.58~0.9` 退回（7 秒一轮，受浪高影响）；
- 每个岸段有 `±0.03` 的相位偏移 → 泡沫前缘是**波浪形的**，不会整条一齐动；
- `wet = max(wet, reach)`，然后按 `exp(-dt*0.14)` 慢慢变干（约 5~7 秒从深湿回到浅湿）；
- 视觉上叠了 4 层：
  1. 外层半湿 `rgba(116,76,44,0.6)`
  2. 内层深湿 `rgba(56,34,18,0.64)`
  3. 湿/干分界线（深色细线）
  4. 冷色天空反光 + 暖色夕阳反光（湿沙的「镜面感」来自这两层）；
- **潮痕**：每次上冲到最高点时记录一份 `reach[]`，画成细白线，10 秒淡出——这就是沙滩上一圈圈的「水线」。

## 5. 礁石

- 礁石剪影烘焙进底图，位置按 `t` 分布在浪区；
- 每帧在石根画白色泡沫圈 + 缓慢摆动的泡沫；
- 浪线靠近时触发 `spawnSpray()`，喷 3~11 颗水珠（抛物线 + 重力）；
- 岸线白浪经过礁石时**断开**（路径 `moveTo` 重置），不会出现「白线穿过石头」。

## 6. 螃蟹（5 只）

状态机：`wander → pause / dig → flee`

- **wander**：横着走，速度随风力略增，方向碰到边界翻转；
- **dig**：停下挖沙，每帧概率喷沙粒，生成一个蟹洞（洞口 + 沙堆），16 秒后消失；
- **flee**：浪线冲到的位置超过螃蟹脚边 → 往右跑 1 秒多，再恢复；
- 绘制：影子 → 4 对腿（`sin(time*14)` 交替）→ 甲壳渐变 → 壳高光 → 两只大螯 → 眼柄 + 眼珠 + 高光；`ctx.scale(dir, 1)` 实现左右翻转。

## 7. 小鱼（7 条）

- 在水域内游动，角度带正弦摆动，碰到岸线/边界反弹；
- 每隔 3~12 秒「溅一下水」：生成扩散的椭圆涟漪 + 一撮水珠，表示鱼在水面活动。

## 8. 微风（风的四种表现）

1. 水面泡沫拉丝被风吹着向岸漂；
2. 干沙上的细沙颗粒被吹着横向飞；
3. 浪线白沫的横向抖动；
4. 沙滩草（代码保留，默认不生成，因为线稿不够好看）。

## 9. 参数

| 参数 | 位置 | 作用 |
| --- | --- | --- |
| 风 | HUD 滑杆 / `params.wind` | 泡沫漂移、沙粒、螃蟹移动速度 |
| 浪 | HUD 滑杆 / `params.wave` | 浪高、上冲距离、上冲周期 |
| 上冲距离 | `maxReachAt(t)` | 湿沙带最大宽度 |
| 上冲周期 | `swashPeriod = 7.0` | 越小，浪越密 |
| 湿沙变干 | `Math.exp(-dt * 0.14)` | 越大干得越快 |
| 浪线数量 | `initWaves()` 里的 `i < 8` | 越多越碎 |

## 10. 性能

- 静态层烘焙一次；每帧主要是 8 条浪线（各 2~3 次路径）、64 段湿沙（4~6 个多边形）、几十个动物绘制；
- 粒子上限 420，超了从头的丢弃；
- 1440×900 下软件渲染仍能跑到 40~80fps（机器不同波动较大），GPU 下稳定 60；
- 雷区：每帧 `createRadialGradient` 太多、逐段 `stroke` 而不合并路径、DPR 超过 2。

## 11. 接到 SONORA 的 `beach` 场景

现有实现是 `waveBands()` + 6 条正弦线（在 `src/ambience.js` 里）。可以按这个顺序升级：

1. 保留 canvas 与透明背景；
2. 用「岸线数组 + 湿沙/上冲系统」替换 `drawBeach()`（本项目 `beach-lab.html` 的 `segs / updateSwash / drawWetSand / drawSwashSheet` 可以直接搬）；
3. 浪线改成 6~8 条相位推进的曲线；
4. 加螃蟹/小鱼（它们只依赖 `shoreXAt()` 与边界，和主项目无关）；
5. 透明画布没有天空，可作为「前景湿沙条」叠在粒子场景下方（`horizon` 取 `H*0.62`，只露出沙滩和浪）；
6. 想要完整夕阳海景：把 `beach-lab.html` 的烘焙层（天空/海/沙）也搬过去，或直接把这个页面挂成独立场景。
